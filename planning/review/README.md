# Reviewing agentic code

Analyses from the [analyze-function](.cursor/skills/analyze-function/SKILL.md) skill for svartz packages live here. Contents of this directory are "ephemeral", meaning they should be gitignored. This only exists for local review (of agentic work).

- **One file per function** (or per analysis request).
- **Naming**: `config/<module>-<function>.md` (e.g. `config/resolver-mergeThemes.md`, `config/loader-resolveConfigPath.md`).
- Use these to go over findings and draft a plan to fix issues (DRY, inlining, DI, export surface, etc.).
