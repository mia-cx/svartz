WebSocket endpoints and browser routes render as reference operations. `operation.protocol: websocket` shows a `WS` badge and the path, the upgrade's parameters and handshake responses, `messages` by direction, and `close` codes, with connection examples in websocat, JavaScript, and Python. `client: browser` on a REST operation shows its request as an HTML form and raw HTTP in place of cURL, fetch, and requests. Responses take `headers`, shown on the page and as an HTTP status line in the examples, and a path with a query joins its query parameters with `&`.
