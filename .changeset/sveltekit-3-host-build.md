Build SvelteKit 3 hosts. `svartz build` runs Vite's app builder, so SvelteKit 3 builds its server, prerenders, and runs the adapter; SvelteKit 2 hosts build as before. A host that only lists notes or links their Markdown imports `virtual:svartz/index`: each vault's published index and site metadata, without Svartz's page runtime.
