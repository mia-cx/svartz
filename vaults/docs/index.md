title: "Svartz"
description: "Publish an Obsidian vault as a SvelteKit site."
---

Svartz turns an Obsidian vault into a SvelteKit site. Use it for a notebook, a wiki, a blog, or documentation. Your notes stay in Markdown. You do not need a SvelteKit app unless you want to publish inside one you already run.

## Build your first site

1. In an empty directory, run `npx svartz@latest init`.
2. Edit `vault/index.md` and run `npm run dev`. Open the URL printed in the terminal.
3. Run `npm run build` and publish the output using your [[start/deploying|deployment target]].

See [[start/installation|Installation]] for Node.js requirements, [[start/first-site|Your first site]] for the full example, or pick a [[themes|theme]].
