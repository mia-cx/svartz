---
title: Harbour developer docs
description: Find adoptable pets over HTTP, GraphQL, or MCP, with one set of schemas.
---

Harbour runs adoption for a network of animal shelters. Apps call its HTTP API or its GraphQL endpoint. AI agents call the same operations as MCP tools. Every surface returns the same [Pet](schemas/Pet.md) object.

Start with [Getting started](guides/getting-started.md).
